MY ATTENDANCE PRO - ஆரம்ப Android project

இந்த ZIP நேரடியாக install செய்யும் APK அல்ல; APK உருவாக்கும் source project.

முதல் பதிப்பு:
- Personal / Company என தனித்தனி attendance mode
- Manual Punch IN / OUT
- கடந்த 31 நாட்களின் punch history
- மாதாந்திர recorded hours summary
- Per-day salary estimate
- Offline storage on this phone

முக்கியம்:
- Hikvision அல்லது company attendance system-இல் இருந்து தானாக data எடுக்க இந்த version-ல் integration இல்லை.
- அதற்கு company வழங்கும் official API / export / permission தேவை. Password-ஐ இந்த app-ல் பகிர வேண்டாம்.
- இது முதல் MVP; payroll-க்கு அதிகாரப்பூர்வ ஆதாரமாக பயன்படுத்த வேண்டாம்.

APK build செய்வது:
1. ZIP-ஐ GitHub repository-க்கு upload செய்யவும்.
2. GitHub-ல் Actions tab திறக்கவும்.
3. "Build My Attendance Pro APK" workflow-ஐ Run workflow செய்யவும்.
4. Build முடிந்ததும் கீழே Artifacts பகுதியில் MyAttendancePro-debug-APK ZIP கிடைக்கும்.
5. அதை download செய்து extract செய்து app-debug.apk-ஐ Android phone-ல் install செய்யவும்.
